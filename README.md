# 💰 Dashboard de Pagamentos - Pintura São Lourenço

Dashboard interativo para controle de arrecadação de valores para pintura em São Lourenço.

## 🚀 Acesso Rápido

**Abra o dashboard:** [dashboard_pagamentos.html](dashboard_pagamentos.html)

Ou acesse diretamente via GitHub Pages quando configurado.

## ✨ Funcionalidades

- ✅ **Entrada de dados em tempo real** - Insira valores de pagamentos
- ✅ **Cálculo automático** - Totais atualizados instantaneamente
- ✅ **Controle por mês** - Agosto, Setembro, Outubro
- ✅ **Exportar em CSV** - Baixe os dados quando necessário
- ✅ **Salvamento automático** - Dados guardados no navegador
- ✅ **Responsivo** - Funciona em desktop e mobile

## 🎯 Como Usar

1. **Abra o arquivo** `dashboard_pagamentos.html` no seu navegador
2. **Insira os valores** nos campos de Agosto, Setembro e Outubro
3. **Veja os totais** atualizarem automaticamente
4. **Exporte os dados** em CSV quando necessário

## 💾 Salvamento de Dados

Os dados são salvos automaticamente no seu navegador usando `localStorage`. Não é necessário salvar manualmente.

## 📥 Exportar Dados

Clique no botão **📊 Exportar CSV** para baixar um arquivo com todos os dados de pagamentos.
